# joat_stores — CLAUDE.md

Multi-tenant SaaS e-commerce platform for Kenyan SMEs.
Solo dev: KAFURAHA. Repo: https://github.com/kafura0/joat_stores

## Stack

| Layer | Tech |
|-------|------|
| Backend | Django 5.2 + DRF, Celery, Redis |
| Storefront | Next.js 15 (`/storefront`) |
| Admin dashboard | Next.js 15 (`/admin`) |
| Database | PostgreSQL (Supabase in prod, local container in dev) |
| Cache / broker | Redis (Upstash in prod, local container in dev) |
| Hosting | Render (backend) + Vercel (frontends) |

## Monorepo layout

```
joat_stores/
  backend/          Django project (cookiecutter-django)
    apps/           Domain apps: store, product, order, payment, restaurant, bar,
                    contracting, analytics, saas, loyalty, ai, notifications, users
    config/
      settings/
        base.py     Shared settings
        local.py    Dev overrides
        production.py  Production overrides (all values from env vars)
    core/           TenantModel base, TenantMiddleware, TenantQuerySet
  storefront/       Next.js customer-facing storefront
  admin/            Next.js merchant dashboard
  nginx/            Nginx config (local Docker only)
  scripts/          Utility scripts
  render.yaml       Render deployment config
```

## Key architecture rules

- **Every domain model** inherits `TenantModel` (UUID PK + `store` FK + soft-delete).
- **Never filter without store_id** — all queries must be scoped to a tenant.
- **TenantMiddleware** resolves `request.store` from the `Host` header or `X-Store-ID` header.
- **JWT claims** include `store_id` and `role`. Four roles: `platform_admin`, `store_owner`, `store_manager`, `customer`.
- **RBAC** is enforced via JWT role claim only — never use `is_staff` / `is_superuser`.
- **Analytics** reads from pre-aggregated `DailyRevenueSummary` + `HourlyOrderSummary` — never live ORM aggregates.
- **Orders** use `items_snapshot` (denormalized JSON) — no separate line-items table.
- **Celery queues**: `order.notifications`, `inventory.alerts`, `billing.reminders`, `payments.reconciliation`, `analytics.reports`.

## Local development

```bash
cp backend/.env.example .env
docker compose up
# Django runs on :8000, storefront :3000, admin :3001, Nginx :80
```

Run migrations + seed demo data:
```bash
docker compose exec django python manage.py migrate
docker compose exec django python manage.py seed_demo
```

## Production deployment (free tier)

See step-by-step in the **Deployment** section below.

Services:
- **Supabase** — PostgreSQL database (free, 500MB)
- **Upstash** — Redis (free, 10k req/day)
- **Render** — Django + Celery worker (free tier, `render.yaml` in repo root)
- **Vercel** — storefront + admin (free, deploy from `storefront/` and `admin/` subdirs)

### Required environment variables for Render

```
DATABASE_URL        postgresql://...?sslmode=require   (from Supabase)
REDIS_URL           rediss://...                        (from Upstash)
CELERY_BROKER_URL   rediss://...                        (same as REDIS_URL)
CELERY_RESULT_BACKEND rediss://...                      (same as REDIS_URL)
DJANGO_SECRET_KEY   (auto-generated by render.yaml)
DJANGO_ALLOWED_HOSTS .onrender.com,localhost
CORS_ALLOWED_ORIGINS https://joat-stores-storefront.vercel.app,https://joat-stores-admin.vercel.app
MPESA_CONSUMER_KEY  (Daraja sandbox or live)
MPESA_CONSUMER_SECRET
MPESA_CALLBACK_URL  https://your-api.onrender.com/api/v1/payments/mpesa-callback/
```

### Required environment variables for Vercel

```
NEXT_PUBLIC_API_URL     https://your-api.onrender.com
NEXT_PUBLIC_DEMO_MODE   true   (admin only — disables auth redirect for demos)
```

## Demo mode

Setting `NEXT_PUBLIC_DEMO_MODE=true` on the admin Vercel deployment bypasses the
login redirect so clients can browse the dashboard without credentials.
The backend still enforces JWT validation on all mutating API calls.

## Seed data command

```bash
python manage.py seed_demo           # creates demo stores, products, orders
python manage.py seed_demo --reset   # wipe and re-seed
```

Creates: 3 stores (retail, restaurant, bar), 4 subscription plans, ~40 products,
25 backdated orders.
